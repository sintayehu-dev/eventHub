# Privacy Policy for Ethio Events

**Last Updated:** April 19, 2026

**App Name:** Ethio Events  
**Package Name:** com.ethioevent.app  
**Developer:** Ethio Events Team

## Introduction

Welcome to Ethio Events ("we," "our," or "us"). We are committed to protecting your privacy and ensuring the security of your personal information. This Privacy Policy explains how we collect, use, disclose, and safeguard your information when you use our mobile application.

By using Ethio Events, you agree to the collection and use of information in accordance with this policy.

## Information We Collect

### 1. Personal Information You Provide

**Account Registration:**
- Email address (for email/password authentication)
- Password (encrypted and securely stored)
- Google account information (when using Google Sign-In: name, email, profile picture)

**Profile Information:**
- Display name
- Profile picture (optional)
- User preferences and settings

### 2. Event-Related Information

**Event Management:**
- Events you create (title, description, date, location, images)
- Events you register for or attend
- Event check-ins via QR code scanning
- Staff assignments and event roles

**Media Content:**
- Photos and images you upload for events
- Event-related media files

### 3. Device and Technical Information

**Automatically Collected:**
- Device type and model
- Operating system version
- App version
- Device identifiers (for analytics and crash reporting)
- Network connectivity status
- App usage patterns and crash logs

### 4. Permissions We Request

**Camera:** For scanning QR codes at events and taking event photos  
**Photo Library:** For selecting and uploading event images  
**Internet:** For syncing data and accessing cloud services  
**Storage:** For caching images and offline functionality

## How We Use Your Information

We use the collected information for the following purposes:

### Service Delivery
- Create and manage your user account
- Authenticate your identity (email/password or Google Sign-In)
- Enable event creation, registration, and management
- Process event check-ins via QR code scanning
- Store and display event photos and media
- Sync your data across devices
- Provide customer support

### Communication
- Send event notifications and reminders
- Notify you about event updates
- Respond to your inquiries and support requests

### App Improvement
- Analyze app usage to improve functionality
- Debug and fix technical issues
- Monitor app performance and crashes
- Develop new features

### Security
- Prevent fraud and unauthorized access
- Protect user accounts and data
- Enforce our Terms of Service
- Ensure platform security

## Third-Party Services We Use

**Firebase Authentication:**
- Manages user accounts and authentication
- Handles email/password and Google Sign-In
- Privacy Policy: https://firebase.google.com/support/privacy

**Cloud Firestore:**
- Stores event data, user profiles, and app content
- Real-time data synchronization
- Privacy Policy: https://firebase.google.com/support/privacy

**Firebase Storage:**
- Stores event images and media files
- Secure file uploads and downloads
- Privacy Policy: https://firebase.google.com/support/privacy

### Google Sign-In
- Third-party authentication service
- Allows sign-in with Google account
- We receive: name, email, profile picture
- Privacy Policy: https://policies.google.com/privacy

### Cloudinary
- Image hosting and optimization
- Processes and delivers event photos
- Privacy Policy: https://cloudinary.com/privacy

### Device and Connectivity Services
- **connectivity_plus:** Checks network connectivity
- **device_info_plus:** Retrieves device information for analytics
- **shared_preferences:** Stores local app preferences

## Data Storage and Security

### Where We Store Data
- **Firebase Cloud Firestore:** User data, events, profiles (Google Cloud servers)
- **Firebase Storage:** Event images and media (Google Cloud servers)
- **Cloudinary:** Optimized event photos (Cloudinary servers)
- **Local Device:** Cached data and preferences

### Security Measures
- All data transmitted is encrypted using SSL/TLS
- Firebase Authentication provides secure user authentication
- Passwords are hashed and never stored in plain text
- Access to data is restricted and monitored
- Regular security updates and patches

### Data Retention
- Active accounts: Data retained while account is active
- Deleted accounts: Data deleted within 30 days of account deletion
- Event data: Retained as long as the event exists
- Backup data: May be retained for up to 90 days

## Specific Features

### QR Code Scanning
- Camera permission is used only for scanning event QR codes
- QR code data is processed locally and sent to our servers for event check-in
- No QR code images are stored

### Image Uploads
- Photos are uploaded to Firebase Storage and Cloudinary
- Images are associated with events and your user account
- You can delete images you've uploaded

### Google Sign-In
- We receive only basic profile information (name, email, profile picture)
- We do not access your Google account data beyond authentication
- You can revoke access through your Google account settings

### Offline Mode
- Some data is cached locally for offline access
- Cached data is encrypted on your device
- Cached data syncs when you reconnect to the internet
